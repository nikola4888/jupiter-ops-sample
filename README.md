# Outside sample ops plan: Jupiter
Open locally: double-click index.html (no build step, no server needed).
Deploy on Cloudflare Pages or GitHub Pages: upload this folder as-is, with index.html at the root and no build command.
All content, links and dates live in data.js; prose sections live in index.html; styling lives in styles.css.
Rule: no number may be added unless it is quoted from a public Jupiter page, with its URL and check date recorded in data.js.
Written from public materials only. Not a client engagement. Not affiliated with Jupiter. Not financial advice. Not a Jupiter document.

Pages:
- index.html: the full sample plan (nine sections; lists render from data.js)
- support.html: support sample: one help article (ASR claims), one troubleshooting tree, one escalation card
- teardown.html: campaign teardown: four Jupiter Mobile posts, 30 Sep to 8 Oct 2026
- raydium.html: contrast memo: a wide product surface with thin routing
- drift.html: contrast memo: a public story that moved on (Drift to Velocity)

Other samples, same method: ../maple-ops-sample/ and ../babylon-ops-sample/ (relative links; they resolve when the repos sit side by side on GitHub Pages).
